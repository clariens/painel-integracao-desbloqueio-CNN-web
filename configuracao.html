Como mudar

Os parâmetros ficam em workflows/code/_regra.js, no repositório. Para mudar:

1. Edite o arquivo e rode npm run inject e npm run check.
2. Cole os workflows de bloqueio, Leitura e Ações no n8n.
3. Faça o commit. Esta tela passa a mostrar os novos valores.

O horário do bloqueio fica no nó "Todo dia 01:00" do workflow de bloqueio.
